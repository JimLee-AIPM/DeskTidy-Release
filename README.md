# DeskTidy

Mac 菜单栏小工具：一键收起眼前不需要的应用，让屏幕保持清爽。适合同时开着很多应用干活的人。

## 能做什么

- **一键清理**：把当前用不到的应用收起来（隐藏，不是关闭），默认快捷键 ⌥⌘K。
- **一键恢复**：把刚才收起的应用全部放回来。
- **工作场景**：每个场景记着清理时要留下哪些应用。内置"AI 工作""做设计""开会"三个场景，也可以自己调整。
- **应用面板**：点菜单栏图标或按 ⌥⌘J，查看正在运行的应用，双击可以切过去。
- **番茄钟**：专注时屏幕角落有一个小时钟，到点提醒休息，随时可以跳过。
- **浅色 / 深色**：默认跟随系统，也可以自选颜色。

## 两个版本

DeskTidy 有两个版本，核心功能一样：

| 功能 | App Store 版 | 完整版（本页下载） |
| --- | :---: | :---: |
| 一键清理 / 一键恢复 | ✓ | ✓ |
| 工作场景 | ✓ | ✓ |
| 番茄钟 | ✓ | ✓ |
| 快捷键 | ✓ | ✓ |
| 在面板里直接退出其他应用 | — | ✓ |
| "很久没用的应用"提醒 | — | ✓ |

App Store 要求应用运行在沙盒里，沙盒不允许一个应用退出其他应用，所以最后两项只有完整版有。

两个版本请不要同时运行，菜单栏会出现两个图标。
